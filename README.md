# IGCSE French 0520 · Listening practice (Paper 1)

Interactive listening papers for Learn French with Haresh Sir.

- Paper pages are shown as images; students tick the boxes on the page.
- 🔍 shows the distractors on the paper, only when a student asks; 🇬🇧 gives English meanings.
- Pausing opens the transcript beside the paper; tap any word for its meaning.
- Practice mode, and an exam mode (recording plays once, no pause, no hints).
- The answer key is encrypted and opens with the teacher code.

`audio/` is not stored in git (original Cambridge recordings). `tools/` holds the scripts that build a paper from the question paper, mark scheme, transcript and audio; the teacher codes are read from the environment (`L_CODE_PAPER`, `L_CODE_MASTER`) and are not in the repo.
